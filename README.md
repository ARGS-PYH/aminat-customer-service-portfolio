# Aminat Abesin — Customer Service Portfolio

A bright, responsive professional portfolio for Aminat Abesin, focused on customer service, client experience, multilingual communication, and operations.

## Features
- Bright coral hero with a complementary purple, aqua, and sunshine palette
- Light/dark theme toggle with preference remembered in the browser
- Responsive navigation and contact links
- Core strengths and experience across aviation, logistics, and real estate
- Language profile: French C1, Mandarin Chinese HSK 2 level (currently learning through the Confucius Institute), English, and Yoruba
- CV downloads: PDF and editable Word-compatible document generated in the browser from the profile data
- Custom favicon and reduced-motion support

## Stack
- HTML5
- CSS with responsive layouts and CSS custom properties
- Vanilla JavaScript
- Google Fonts (DM Sans and Manrope)

No package installation or build step is required. Open `index.html` in a modern browser to preview locally.

## Publish with GitHub Pages
1. Open the repository's **Settings** tab.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.

After GitHub Pages is enabled and deployment completes, the expected URL is:
`https://args-pyh.github.io/aminat-customer-service-portfolio/`

## Before public launch
- Confirm all CV details, dates, and professional claims with Aminat.
- Confirm she is comfortable publishing her phone number and email address publicly.
- The Mandarin entry is intentionally described as HSK 2 level / currently learning, not fluent.
- The CV download is generated from the portfolio's profile data; review it before sending job applications.
- Replace any content she does not want public.
