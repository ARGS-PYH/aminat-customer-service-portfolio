A responsive, single-page professional portfolio for Aminat Abesin, focused on customer service, client experience, and operations.

- Core service strengths
- Language profile (French C1, Mandarin Chinese HSK 2 level and currently learning, English, Yoruba)

- Education, language training, and leadership
- Contact links

## Stack
- HTML5
- CSS (responsive layout, no framework required)
- A tiny inline JavaScript snippet for the current year
- Google Fonts (DM Sans and Manrope)

## Run locally
Open `index.html` in any modern browser. No build or install step is required.

## Publish with GitHub Pages
1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

Once GitHub Pages is enabled and its first deployment completes, the project site should be available at:
`https://ARGS-PYH.github.io/aminat-customer-service-portfolio/`
